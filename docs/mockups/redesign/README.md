## 自動で確かめていること

`vite preview` に Playwright を当てて、毎回この4点を assert している
（第3版で直した「地図を押しても選べない」バグの回帰防止）：

1. 地図の自治体を押すと選択が変わる
2. `.selbar` ／ `#choose` 左の見出し ／ ヒートマップ先頭行 ／ 地図の選択リングが追従する
3. 拡大後にドラッグすると `viewBox` が動く
4. ドラッグでは選択が変わらない
