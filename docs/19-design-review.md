## 1. デザインコンセプト

> **「数字の出どころが、指でたどれる。」**

この作品の主張は「6年後の学童不足を、都の公式データだけで予測した」こと。
ならばデザインの仕事は飾ることではなく、**予測の来歴を画面上で追跡可能にする**ことです。

いまのサイトは物語としてよくできています
（保育園には入れた → 詰むのは6年後 → 巨大数字 → 地図 → ツール → 根拠）。
問題は順序で、**データの話が最後の脚注（11.5px・グレー・最下部）に落ちている**ことです。
データ活用賞を狙うなら、そこが主役側に来ていないといけません。

## 4. 配色・タイポグラフィ・余白・UIコンポーネント

### 配色 — **変えません**

`--accent #1c5cab` と5段ランプは `dataviz` の検証器を PASS 済みです
（`src/ui/palette.ts` 冒頭・最淡 `#86b6ef` は純白面でしか対面2:1を満たさない制約つき）。
**触ると再検証が必要になり、3時間には収まりません。**

追加する色は **ゼロ**。推定マークには既存の `--ink-3` を流用します。

### タイポグラフィ — 中間段を1つ足す

現状は 96px（hero）／64px（sect）／15px（body）で、**中間が無い**。
リード文が本文と同じ重さになり、セクションの入口が弱くなっています。

```css
--fs-hero  clamp(40px,6.4vw,96px)   /* 維持 */
--fs-sect  clamp(30px,4.4vw,64px)   /* 維持 */
--fs-lead  clamp(17px,1.7vw,24px)   /* 🆕 セクション直下のリード専用。1440pxで24px */
--fs-body  15px                     /* 維持 */
--fs-meta  13px                     /* 出典・注記。11.5px から昇格 */
```

⚠️ **28px まで上げないこと。** セクション見出しは `clamp(26px,3vw,42px)` の上書きで
1440px では42pxです。リードを28pxにすると比が1.5倍しかなく、見出しが立ちません。
アートボードは24pxで組んであります。

`.lede` は現状 `clamp(15px,1.5vw,19px)`。これを `--fs-lead` に差し替えます。

### 余白 — セクション間は維持、S4内部だけ直す

- セクション間 120px、S4内部の 78px / 44px の2段リズムは**そのまま**（統一されている）
- `.stage` は `1fr 300px` → `1fr 320px`、`align-items:start` 維持
- `.ctl` の `margin-left:auto` を撤去

### UIコンポーネント — **新規はゼロ。既存の再利用を広げる**

`src/ui/App.tsx:42` の `Tip`（点線下線＋ホバーで吹き出し）がすでにあります。
**これを全数字の出所表示に横展開します。** 新しいコンポーネントは書きません。

```
41  ←  .tip で巻く  →  「教育人口等推計（R7）と学童クラブ実施状況から算出」
```

**「箱（枠線＋影のカード）を使わない」方針は維持します**（`src/ui/styles.css` 冒頭）。
区切りは余白と1pxヘアラインだけ。この潔さは他チームとの差になるので崩さないこと。

### 推定マークの一貫化

いま bridged（都の推計どうしを接続した推定）の表現は**ヒートマップだけ**です
（45°ハッチ＋`--accent` の縦罫）。これを **地図・折れ線・詳細の巨大数字**にも通します。

データの限界を隠さない姿勢が全画面で一貫し、これはデータ活用賞に直接効きます。

## 5. PC とスマホのレイアウト方針

**PC 1440px が主戦場。** `.mid` の max-width 1180 / padding 40 は維持。

スマホは「崩れない」ところまで（実機確認の記録が無いので、まずそこから）：

| 箇所 | 現状 | 手当て |
|---|---|---|
| `.ctl` | `margin-left:auto` が効いて折り返し位置が乱れる | @media で `auto` 解除・縦積み |
| ヒートマップ `.grid` | `74px + repeat(12,1fr)`。390pxでは1列27px・数字9.5px | `overflow-x:auto` の容器に入れ、自治体名列を `position:sticky; left:0` |
| `.facts` | `gap:34px` | 20px |
| S3 スクロール地図 | `height:340vh` | スマホでは 220vh（指のスクロール量が多すぎる） |

@media は現状 900px の1本のみ。**640px を1本足す**のが最小の追加です。
