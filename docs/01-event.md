## 概要

| 項目 | 内容 |
|---|---|
| 名称 | 都知事杯オープンデータ・ハッカソン2026 |
| 主催 | 東京都 |
| 運営事務局 | みずほリサーチ&テクノロジーズ |
| 開始年 | 2021年（2026年度で6回目） |
| 公式サイト | https://odhackathon.metro.tokyo.lg.jp/ |
| 公式ガイドブック | https://odh-tokyo2026.code4japan.org/ （Code for Japan 運営） |
| 問い合わせ | `9_opendata-hackathon.tokyo@mizuho-rt.co.jp` |

東京都オープンデータカタログサイトに掲載されているオープンデータ等を活用し、
社会課題の解決に向けたデジタルサービスを企画・開発するイベントです。

## 部門

| 部門 | 内容 | 2025年度のFinal Stage枠 |
|---|---|---|
| **サービス開発部門** | オープンデータを活用したデジタルサービスの企画・開発 | 18チーム |
| **ビジュアライズ部門** | オープンデータの可視化・分析を競う | 3チーム |
| **アイデア提案部門** | オープンデータによる課題解決のアイデアを競う | 3チーム |

Final Stage には**24チーム**が進出します。

## 賞

2026年度は**都知事杯（最優秀賞）・オーディエンス賞を含む8賞**が設定されています。

※「9つの賞」と表記しているソースもあり、正確な数と内訳は要確認
（2025年度は学生賞を新設して計10賞でした）。

### Final Stage 進出チームへの特典

- 開発したサービスに対する**実装支援プログラム**（年度末までのリリースを目指す）
- **東京ポイント 500pt/チーム**
- デジタルバッジ

## 応募条件

募集要項より（要一次情報確認）：

1. 東京都が抱える社会課題の解決に資するサービスを検討していること
   - 参加者による自由な提案に加え、**東京都が提示するテーマへの提案も可**
   - 各局や区市町村等が提示する現場の課題への提案も可能
2. **東京都のオープンデータ等（オープンデータや民間データ等）を活用予定であること**
3. 募集要項に記載されている留意事項すべてに承諾できること

## 提出物

1. **プロトタイプ等**（ハッカソン期間中に開発したもの）
2. **プレゼンスライド**（First Stage 収録用）
3. **2分程度のプレゼン動画**（事前収録。スケジュールを予約する）

## 審査

- First Stage / Final Stage は**すべての作品を共通の審査基準で審査**
- 収録したプレゼンテーション動画等をもとに、審査委員が評価
- 判明している審査観点：

  > 「オープンデータが有効に活用され、かつ、独自性のある優れたアイデアが
  > 提案されているか」

**正式な評価項目（配点や観点の内訳）は未確認です。** → `docs/06-open-questions.md`

## 事務局提供ツール（申請制・9月末まで）

2026年度の参加チーム向けに、事務局から2つのツールが提供されています。

### 1. 生成AI開発ツール（OpenCode + Cloudflare Workers AI）

コマンドライン上で動作する生成AI開発ツール。チャット形式でコードの生成・修正・
説明を指示できます。

マニュアル：https://odh-tokyo2026.code4japan.org/39a3e9710744804c82f0c30bc6f6db25

### 2. サービス公開環境（Cloudflare Paidプラン相当）

→ **デプロイ先は Cloudflare（Workers / Pages）を前提にするのが素直です。**
技術方針は `docs/05-tech.md`。
