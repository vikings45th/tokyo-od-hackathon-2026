## 概要

| 項目 | 内容 |
|---|---|
| 名称 | 都知事杯オープンデータ・ハッカソン2026 |
| 主催 | 東京都 |
| 運営事務局 | 都知事杯オープンデータ・ハッカソン運営事務局（受託者：株式会社みずほ銀行） |
| 問い合わせ | `9_opendata-hackathon.tokyo@mizuho-rt.co.jp` |
| 公式サイト | https://odhackathon.metro.tokyo.lg.jp/ |
| 公式ガイドブック | https://odh-tokyo2026.code4japan.org/ |

東京都が保有するデータを公開し、シビックテックや民間企業と共に新たなサービスを
創出する取組の一環。**オープンデータや民間データ等を活用して社会課題の解決に向けた
サービス開発を競い合う**イベントです。

### 応募対象者

オープンデータや民間データ等を有効活用したサービス開発を目指す個人又は団体。
一人でも参加可能ですが、**複数人でのチーム参加が推奨**されています。

### 応募条件

1. 東京都が抱える社会課題（都民から寄せられたテーマ＋自由提案も可）の解決に資する
   サービス案を検討又は検討予定であること
2. **オープンデータや民間データ等を活用予定であること**
3. 学生賞の対象は、メンバーが高校生・高専生・専門学生・**大学生（大学院生は除く）**
   のみで構成されていること（※アドバイザー枠として職業・年齢を問わないメンバーを1名参加可能）
4. 暴力団関係者、風俗関連業・ギャンブル業等、公的支援先として不適切な業態を営む者を除く

## 審査基準【最重要】

First Stage / Final Stage 共通で、以下の5項目で審査されます。

| 基準 | 内容（募集要項原文） |
|---|---|
| **データ活用** | サービスにおいてオープンデータや民間データ等を有効活用しているか |
| **アイデア力** | 都民の課題・問題意識の解消、希望・期待の実現に向けたアプローチ手法やアイデアが秀逸で、サービスとして成立しているか |
| **技術力** | 技術難易度が高い、技術要素(アーキテクチャやAI等)に合理性がある等、技術力が確かで完成度も高いサービスであるか |
| **ソーシャルインパクト** | 手取り時間の増加等、都民のQOL向上に貢献するような社会的インパクトがある実現可能性が高いサービスとなっているか |
| **サービスデザイン** | 利便性や満足等、都民目線での価値を持続的に提供できるサービスとなっているか |

### 審査方法

- **First Stage**：提出作品を**6人の審査委員**が2分プレゼン動画等をもとに審査し、
  Final Stage 進出の**24作品**を選出。審査委員は民間や行政での経験が豊富で多様な顔ぶれ
- **Final Stage**：審査基準に基づき、**審査委員の評価＋当日の視聴者投票**により審査

## 提出物

作品提出時に**以下のすべて**を提出します。

### 1. フォームへの入力項目

> ✅ **フォームの実物を確認しました。全項目は [`docs/12-submission-form.md`](12-submission-form.md) にあります。**
> ここに書いていた「エントリー項目①〜⑥・各300文字程度」は募集要項からの推定で、
> **実物とは構造が違いました。** 記入時は必ず `docs/12-submission-form.md` を見てください。

実際のフォームは**7セクション**構成です。

| セクション | 主な内容 |
|---|---|
| 1. チーム情報 | チーム名（**変更不可・公開**）／フリガナ／人数／連絡担当者／**学生賞の対象か**／メンバー構成と役割／運用体制 |
| 2. 作品の概要 | 課題の種類／作品名（**変更不可・公開**）／サービスの詳細／着目した課題・背景／解決方法 |
| 3. 技術詳細 | 技術選定の理由／**生成AI等の活用方法**／デモURL／ハードウェアの有無／操作動画 |
| 4. オープンデータの利用状況 | 利用データ一覧（**他自治体・民間データも可**） |
| 5. プレゼン資料 | スライド（**必須**）＋ **画面キャプチャ（必須・最大3枚）** |
| 6. First Stage 収録日予約 | **収録方法・言語をここで選ぶ**（＝提出と同時に予約） |
| 7. 技術・権利関係の確認及び同意事項 | チェック3項目 |

> ⚠️ **必須の自由記述は 310文字 × 5項目**（2-3／2-4／2-5／3-1／3-2）。
> 加えてメンバー構成・運用体制・利用データ一覧があります。当日に書き始めると間に合いません。

### 2. プレゼン資料（**必須**）

PowerPoint / PDF・**最大100MB**・**比率16:9**。First Stage の2分間プレゼン用。

### 3. 画面キャプチャ（**必須**）

JPEG / PNG・**最大3枚**・推奨 **1600×900px**。
「最大3枚まで」という書き方ですが**必須項目**です。見落とし注意。

### 4. 2分程度のプレゼン動画（事前収録・**予約は提出フォームのセクション6**）

### 5. デモURL または操作動画（**任意**）

※ 操作動画は**60秒以内**。ハードウェア系は必須、ソフトウェア系は任意。
**音声を利用する作品以外は無音**にすること。デモURLを記入済みなら不要です。
