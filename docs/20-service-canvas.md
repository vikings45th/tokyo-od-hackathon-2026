## 利用者エリア

### 利用者はどんな人？

**正社員×正社員の共働き夫婦。第一子は0〜5歳。いま東京で初めての持ち家を探している。**

- 世帯収入は中間層〜上位まで幅広い
- 現在の住まいは都内・都外を問わない（**地方・海外からの転入を含む**）
- 子の「いまの年齢」ではなく「**将来この子が小1になるタイミング**」で行動する
- 保育園はすでに入れた、または入る目処が立っている

> 🔴 **世帯の中に読者が2人いて、前提が非対称です。**
> 「小1の壁」という言葉の認知は **共働きママ 64.1% ／ パパ 2割台**
> （東京ガス都市生活研究所）。**家の購入は2人で決めるのに、片方はこの言葉を知りません。**
> → 画面は「知っている側が、知らない側に見せる道具」としても成立させる。
> 　 語に頼らず、起きることを具体的に書く（`src/index.html` と S0 の lede がその役割）。

### 困りごと

- **区ごとの学童の入りやすさを、比べる方法がない。** データは公開されているが、
  CSVはヘッダが6行目・区部と市町村部が横並び2ブロック・数値は `"1,261 "` 形式で、
  **購入検討者が扱える形になっていない**（`docs/13` §1-2 検証4）
- 不動産サイトも区役所も、**答えるのは「今年の」待機児童数だけ**。将来の見通しがどこにもない
- **待機児童数では順位が付かない。** 48自治体中18が待機ゼロ（2025-05 実測）。
  しかも「申込前に断念した人」は待機にも登録にも計上されない
  ——**この課題仮説の当事者そのものが、指標に現れない**
- 江戸川区のように**制度が別枠**の自治体があり、単純比較すると誤情報になる

### 嬉しいと感じること

- 検討しているエリアと、その隣のエリアを**並べて比べられる**
- 「**あなたの子が小1になる年**」という、自分の意思決定に直結する時点で見られる
- 予測が**どれくらい当たるか（外れるか）まで開示されている**ので、鵜呑みにせず判断できる
- 数字が悪かったときに、**打てる手が示される**（不安を煽られて終わらない）

### 利用者がもっとも実現したいこと

> **住宅ローンを組む前に、「この街に住んだらどうなるか」を6年先まで見て、納得して決めること。**

`docs/12` の核心：**意思決定する時点と、痛みが出る時点が最大6年ずれる。**

```
2026年  0歳の子がいる。家を買う      ← 意思決定はここ
              ↓ 6年
2032年  子が小1。学童に入れない      ← 痛みはここ
```

## 価値エリア

### 利用者の価値

「もっとも実現したいこと」をさらに深掘りする（ガイドライン p.39 の手順）。

```
もっとも実現したいこと      なぜそれが欲しいのか        利用者の価値
─────────────────────────────────────────────────────────────────
6年先まで見て決めたい   →  外したときに戻れない     →  ● 取り返しのつかない選択を、
                            から                          自分の手で確かめてから下ろせる

                        →  「知らなかった」で       →  ● 数年後に後悔する材料を、
                            片方が仕事を減らす            いま潰しておける
                            事態を避けたい

                        →  夫婦で判断を揃えたい   →  ● 片方しか知らなかった論点を、
                                                          同じ画面を見て共有できる
```

🔴 **「調べる時間の短縮」を価値として書かないこと。**
このサービスの価値は「**取り返しのつかない意思決定を、間違えないこと**」（`docs/13` §3）。
そう書いた方が強く、かつ正直です。「◯時間削減」を根拠なく書かない。

### 提供者の価値

- 都が持っているのに**比較可能な形になっていないデータを、住民の意思決定に使える形にする**
- **同じ画面が、自治体の学童整備計画の需給見通しにも使える**
  （行政審査員3人がいる審査構成で効く。Final Stage 後の GovTech東京の実装支援とも接続する）
- 使うのは**毎年更新される都の公式データだけ**。APIキーもDBも持たないので、
  **年1回の差し替えで生き続ける**（審査文言「持続的に提供できるか」への回答）

## チェックすべきこと（ガイドライン p.37・p.39 の指定項目で自己検査）

| 項目 | 判定 | 根拠 |
|---|---|---|
| 全ての人の要望に応えるのではなく「**深刻な問題を抱えている人**」を設定したか | ✅ | 「保育園には入れた・これから家を買う・第一子0〜5歳」まで絞った。まだ保育園に入れていない人は意図的に外している |
| 利用者の**状況・感情**に基づいて記入したか | ✅ | 杉並区で申込前に断念した実体験（`docs/13` §1-1）が起点 |
| 困りごと・嬉しいこと・実現したいことの**整合性** | ✅ | 困りごと（比べられない・将来が見えない）→ 嬉しいこと（比べられる・6年先が見える）→ 実現したいこと（納得して決める）で一本 |
| **誰にでも当てはまることを書いていないか** | ⚠️ | 「小1の壁は大変」は誰にでも当てはまる。**画面でこれを言わない。**「その家に」「あなたの子が小1になる年」のように、**常に読者の固有の状況に接地させる** |
