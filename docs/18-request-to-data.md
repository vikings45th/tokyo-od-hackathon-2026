## 🔴 依頼1【最優先】`data/app/data.json` を49自治体ぶん

**これが出ないと作品が成立しません。**

いま `src/ui/data.ts` は `sample.json`（6自治体）を読んでいて、**地図の43自治体がグレー**です。
hero には「東京都オープンデータ ／ 49自治体」と書いてあります。
**この画面のまま2分動画を撮ったら、データ活用賞の芽は消えます。**

対象は **23区 ＋ 多摩26市 ＝ 49自治体**（島嶼部・郡部は母数不足のため対象外。
`SMALL_SAMPLE_N0 = 500` で除外されます）。

### 型（②が `src/types.ts` に定義。★が新規）

```
Muni {
  code, name, area,
  official[]        // 都の公式推計（令和7〜12）
  entrants[]        // 就学予定者
  baseChildren      // 2025-05-01 の公立小学校児童数（＝分母 N0）
  children2023      // 🔴 残してください（後方互換）
  childrenSeries[]  // ★新規：{ asOf, count } × 5点（2021〜2025 の 5-01）
  gakudo[]          // ★6点に増える：{ asOf, clubs, registered, waiting }
  note?             // 制度差・外れ値の注記
}
```

- **`gakudo` は 2021/2022/2023/2024/2025/2026 の 5-01。**
  2025-10-01 を入れるかは①判断（②は 5-01 の年次系列だけを使います）
- **`childrenSeries` は 2021〜2025 の5点。** 2026 は分母が無いので入れない
- 🔴 **`baseChildren` / `children2023` は残す。**
  消すと `sample.json` と③の画面が壊れます（段階移行のため）

## 🔴 依頼2【提出要件】出典表記の分離を、画面データにも反映する

`data/SOURCES.md` は2ブロックに分けてもらいましたが、**画面に出ているのは
`AppData.sources[]`** です（S5「根拠」セクション。`{ name, provider, license, url, retrievedAt }`）。

```
・カタログ掲載分（教育人口等推計・公立学校一覧・学校基本統計）
    → license: "CC BY 4.0"

・福祉局の公表資料（学童クラブの年次系列）
    → 🔴 license に "CC BY 4.0" と書かない。
       「東京都福祉局 公表資料」等、事実に合う表記にする
```

**まとめて「いずれも CC BY 4.0」と書くと事実に反します。**
スライド・動画・提出フォーム項目⑤でも分けたまま使ってください。

### 3-2「生成AI等の活用方法」（310字）に書ける内容が、今日できました

**実装を足す必要はありません。今日の調査そのものが実話として強い**です。

> Claude Code（Anthropic）を設計・実装・データ検証に使用。工夫は、**AIに結論ではなく
> 検証をさせた**点です。当初は待機児童数でエリアを順位付ける設計でしたが、全62自治体を
> 集計させたところ30自治体が待機0で順位が付かないと判明し、主指標を登録率へ変更しました。
> さらに、2時点のデータから引いた自治体別トレンドが妥当かをAIに再調査させた結果、
> 豊島区の −1.82pt/年 が2点由来の誤りだと分かり、**公表資料を遡って5時点に増やして訂正**
> しました。数値は決定論的なコードでのみ生成し、AIの出力は必ず元データで裏を取っています。

**「開発にAIを使いました」は今年の応募の大半が書きます**（事務局が OpenCode と
