## 目的

都知事杯オープンデータ・ハッカソン2026 の審査で **データ活用賞**を獲ること。
審査基準は「オープンデータや民間データ等を有効活用しているか」。

二次的な目的として、実際に東京都で子育てをしている世帯が使えるものであること。

1. **審査員6人**（行政3人＋民間3人。Eukarya〈Re:Earth〉CEO、Zaim創業者、

## 制作対象

既存の1ページ構成の React SPA。**PC 1440px が主戦場**、スマホは「崩れない」ところまで
（現状 `@media` は 900px 1本のみ、実機確認の記録なし）。

サービス名は「小1の壁マップ」。保育園には入れたのに小1で学童に入れず、親のどちらかが
働き方を変えることになる——という問題を、**引っ越す前に**知るためのものです。

## ユーザーにしてほしい行動

自分の子の生まれ年月を入れて、**引っ越し先の候補にしている自治体の、その子が小1になる
年度の学童不足率を見る。** そして「この数字は東京都の公式データから出ている」と納得する。

## 掲載する内容・機能

いま実装されているもの（すべて動いています）：

- 東京都49自治体のコロプレス地図（クリックで選択、スクロールで拡大、ドラッグで移動）
- リスクの高い自治体ランキング 上位10件
- 選択自治体の詳細（不足人数、需要、受け入れ実績、待機児童、クラブ数）
- 需要と受け入れ実績の折れ線＋予測区間
- 12年度 × 自治体のヒートマップ（いつ悪化するか）
- シナリオ切り替え（登録率トレンドのプリセット）
- スクロール連動で年度が進む地図の物語（2026→2038）
- バックテスト結果と出典

使っているデータ（**8件・すべて CC BY 4.0**）：

| データ | 提供 | 件数 |
|---|---|---|
| 教育人口等推計（令和5・6・7年度版） | 東京都教育庁 | 3 |
| 公立学校統計調査報告書【東京都公立学校一覧】（令和5・6・7年度版） | 東京都教育庁 | 3 |
| 学童クラブ事業の区市町村別実施状況（2023-05 / 2025-05 / 2025-10） | 東京都福祉局 | 1 |
| 国土数値情報 行政区域データ | 国土交通省 | 1 |

4つを **muni_code（全国地方公共団体コード5桁）** で結合しているので、自治体名の
表記ゆれを一度も踏んでいません。**これは訴求点です。**

実測値（画面が実行時に計算する本物の数字。これ以外を書かないこと）：

- バックテスト誤差：1年先 0.93% ／ 2年先 1.37%（n=49）
- 登録率トレンド：**+0.81pt／年**（48自治体・24.0% → 25.6%・江戸川区は計上方法が
  変わったため除外）
- 出力：49自治体 × 12年度 ＝ 588セル
- 2031年度以降は、都の推計3世代を接続した推定（画面上でハッチで区別している）

素材や文言が未確定の箇所は、仮の内容を提案してかまいません。

## ブランド・トーン

**目指す印象**：東京都の公式データを扱っている信頼感。静かで、密度があり、
数字が主役。読ませるより、**触らせて分からせる**。

**避けたい印象（最重要）**

> **「パワポで作った資料を PDF にしたもの」に見えること。**

いまのサイトがまさにそう見えています。原因は分析済みで、次の3つです：

1. `#s0`〜`#s2` に `min-height:100vh` が付いていて、1画面＝1枚で完結する。
   スクロールが「読む」ではなく「めくる」動作になっている
2. 6セクションが全部同じ型（eyebrow → 見出し → リード → 中身）の繰り返し。
   スライドマスターを使い回した資料と同じリズム
3. **触れる面が5番目に埋もれている。** ヘッダーもナビも固定要素も無く、
   「これは読み物です」という信号しか出ていない。道具に見えてくるのが遅すぎる

**この3つを構造から解いてください。** 装飾を足して誤魔化す方向ではありません。

他に避けたいもの：安っぽさ、過度に未来的な演出、情報過多、
角丸＋左ボーダー＋薄いグラデのカード（AI が作った感が出ます）。

**既存のデザイン資産（引き継ぐもの）**

- 配色：`--accent #1c5cab`／5段ランプ `#86b6ef #5598e7 #2a78d6 #1c5cab #0d366b`／
  地の色 `#ffffff #fcfcfb #f4f4f2`／文字 `#0b0b0b #52514e #8a8983`／罫 `#e6e6e1`。
  ダークテーマあり
- タイポ：`-apple-system, "SF Pro Display", "Hiragino Sans", "Noto Sans JP"`、
  本文15px/1.6、`font-feature-settings:"palt" 1`、見出しは 800 で字間 -.035em
- **「箱（枠線＋影のカード）を使わない」**：区切りは余白と1pxのヘアラインだけ

## 制約

- **React 19 / Vite 8 / TypeScript で実装可能な構成にすること。**
  `package.json` と `vite.config.ts` は別の担当者の所有物です。
  **新規依存を増やさない前提**で設計してください（現在 d3-geo と topojson-client のみ）
- 触ってよいのは `src/ui/` の中だけ。`src/core/`（予測エンジン）と `data/` は別担当
- **`src/ui/palette.ts` は変更しないこと。** コントラスト検証を通しています。
  ライトテーマの最淡色 `#86b6ef` は純白系の面でないと対面2:1を割るので、
  **セクション背景をグレーにできません**（`#f7f7f5` は 1.97:1 で FAIL）
- WCAG を意識し、文字サイズとコントラストを確保すること。ダークテーマでも成立させること
- データはビルド時に import 済み。実行時のネットワークアクセスは無し
- **出典とライセンス表記は必須**（大会の提出要件）。JavaScript 無効時にも
  出典が読めるようにしてあるので、その担保を壊さないこと
- 画像は仮素材でよい。ただし地図は実データの SVG パスで描かれています
- ⏰ **提出は 2026-08-23 17:00。** 実装に使える時間から逆算した現実的な案にしてください。
  「時間があればこうしたい」は分けて書いてください
