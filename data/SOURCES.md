## データ定義（①の作業指示書）

### 1〜3. 教育人口等推計（東京都教育庁）

| | |
|---|---|
| データセット | `t000021d2000000193`（令和7年度）／`t000021d2000000189`（令和6年度）／`t000021d2000000178`（令和5年度） |
| 文字コード | **CP932** |
| 結合キー | `区分１`（自治体名。`Muni.name` と一致させる） |

**使うリソース**

| ファイル | 中身（実測） | 用途 |
|---|---|---|
| `25es_result01` | **62区市町村 × 学年別（1〜6年生）× 令和7〜12年度**・1,313行。**全都のみ令和20年度まで** | 予測の軸・`bridged` の接続元 |
| `24es_result01_c` / `23es_result01` | 同形式 | **バックテスト**（1年先・2年先） |
| `25es_survey` | **住宅種別 × 学年別の児童発生率**（1戸あたり） | シナリオ（住宅開発）の係数 |
| `25es_iadtable` | コーホート増減率（区部/市町村部別・実績5年＋推計。**13年度以降の列もある**） | 参考 |

**⚠️ 落とし穴**

- 🔴 **`result01` と `result02` を間違えないこと。** `result02` は**学年が無い**69行の粗い表です。
  **`result01` でないと学年別が取れません**
- 縦持ち（`区分１`＝自治体、`区分２`＝就学予定者/小学校/中学校、`区分３`＝学年や「N年後」）
- **列名が和暦**（`７（実数）`, `8`, `9`, …）。`７（特別学級児童生徒実数）` という**別列が混ざる**
- **区市町村は令和12年度まで、全都だけ令和20年度まで**（設計書 §5-2）
- **`就学予定者「０年後」` の R7 値は 2026年度入学**（＝翌年度入学）。年度のずれに注意

```bash
# 学年別が取れることの確認
curl -sSL "https://www.kyoiku.metro.tokyo.lg.jp/documents/d/kyoiku/25es_result01" \
  | iconv -f cp932 -t utf-8 | grep '^全都,小学校,１年生'
```

### 4〜6. 公立学校統計調査報告書【東京都公立学校一覧】（東京都教育庁）

| | |
|---|---|
| データセット | `t000021d2000000191`（令和7年度）／`t000021d2000000186`（令和6年度）／`t000021d2000000176`（令和5年度） |
| 文字コード | **CP932** |
| 結合キー | **`学校番号`**（3ヴィンテージ共通）／`設置者`＝自治体名 |
| 実測 | **公立小 1,255校 × 学年別児童数 ＋ 学級数 ＋ 教員数**（103KB） |

**使うリソース**

- `r7_shougakkou_ichiran` / `r6_shougakkou-ichiran` / `shougakkou-ichiran_9` … 児童数・学級数
- `r7_shougakkou_address` / `r6_shougakkou-address` / `shougakkou-address_4` … 住所

**⚠️ 落とし穴**

- **多階層ヘッダ**（`児童数(通級生を除く。)/１学年` のようにスラッシュ区切り）
- **欠測は `-`**（0ではない）
- **公立のみ。私立小は入りません**
- **住所に区市町村名が入っていない**（例：`麹町2-8`）。`設置者` と組み合わせること
- **緯度経度は無い。** ジオコーディングが必要な場合は**ローカルで実行**
  （`msearch.gsi.go.jp` はクラウドセッションから CONNECT 403）
- 令和5年度版だけURLの命名規則が違う（`shougakkou-ichiran_9`）

### 7. 学童クラブ事業の区市町村別実施状況（東京都福祉局）

| | |
|---|---|
| データセット | `t000054d0000000344` |
| リソース | `r50501gakudoujoukyou`（2.4KB・71行） |
| 文字コード | **CP932** |
| 基準日 | **令和5年5月1日（＝2023年度）** |
| 原典 | **こども家庭庁成育局成育環境課実施調査**（CSVの3行目に明記） |

**⚠️ 落とし穴**

- 🔴 **ヘッダは6行目**（1行目はタイトル、5行目に単位）
- 🔴 **区部と市町村部が横に並んだ2ブロック構成。** 1行に2自治体分が入っています
- 🔴 **数値が `"1,261 "` 形式**（カンマ＋末尾スペース＋引用符）
- 🔴 **カタログ上のリソースは1本＝1時点のみ。トレンドが取れません**
- 🔴 **48%（62中30）が待機児童数0。** 待機児童数を主指標にすると比較できません
- 🔴 **「申込前に断念した人」は待機児童数に含まれません**（要件 §1-2 検証1）
- 🔴 **江戸川区は制度が別枠**（全児童対象の独自事業。登録141人・クラブ4か所）。
  **スコア対象から外すこと**（設計書 §4-4）

```bash
# ヘッダが6行目・2ブロック構成であることの確認
curl -sSL "https://www.fukushi.metro.tokyo.lg.jp/documents/d/fukushi/r50501gakudoujoukyou" \
  | iconv -f cp932 -t utf-8 | sed -n '1,9p'
```

## 外部データ（国・民間）— 未取得

**事務局は民間データの活用も歓迎とのこと。ただし次の2点を守ってください。**

> ⚠️ **「歓迎」は利用規約の確認を免除しません。** 都のカタログ掲載データと違い、
> 外部データは**自分で規約を確認する必要があります**（`CLAUDE.md`）。
> **審査用動画は YouTube で一般公開されます。** 規約が曖昧なもの・
> スクレイピング前提のものは使わないこと。
>
> ⚠️ 応募条件は「**東京都のオープンデータ等を活用**」です。**都のデータが主役**の構成を崩さないこと。

**クラウドセッションからは全て CONNECT 403**（実測）。**ローカルで取得して `data/raw/` にコミット**します。

| 優先 | データ | 何が解決するか | 状態 |
|---|---|---|---|
| 🔴 **最優先** | **こども家庭庁「放課後児童健全育成事業（放課後児童クラブ）の実施状況」** | **`Scenario.trend` の実測値。** 設計書 §0-2 のとおり**この値がモデルを支配します**。上記7の原典なので整合性も説明できる | **未取得。①がローカルで15分** |
| 中 | こども家庭庁「保育所等関連状況取りまとめ」 | 軸2の待機児童数（都のカタログはPDF中心） | 未取得 |
| 中 | 国交省 不動産情報ライブラリ／地価公示 | 軸候補「住宅価格」 | **APIキー申請が8/23に間に合うか要確認** |
| 低 | 国土数値情報（駅・鉄道） | 軸候補「通勤時間」 | **経路探索は1.5日では重い。v1では非推奨** |

**取得したら、このファイルに1行ずつ追記してください**（名称・提供元・形式・粒度・**ライセンス**・URL・取得日）。

## ライセンス確認の手順

```bash
# カタログ上の license_title
curl -sS "https://catalog.data.metro.tokyo.lg.jp/api/3/action/package_show?id=<ID>" \
  | python3 -c "import sys,json;print(json.load(sys.stdin)['result']['license_title'])"
```

> ⚠️ **`license_title` が CC BY でも、データに同梱された README・注意事項に
> 別の条件が書かれていることがあります。** 必ず開いてください。
> 実例：`土地利用現況調査GISデータ`（都市整備局）は**「その他」**で、
> 同梱文書に「資料作成等で引用される際には、著作権法上の手続き等が生じる」と
> 書かれていました（`docs/03-data.md`）。
>
> ⚠️ カタログには**区市町村のデータも多数含まれます**。
> 都庁以外の自治体のデータは**参加者自身で利用規約を確認し、必要に応じて個別に許諾申請**が要ります。
> **本作品では区市町村のデータは1件も使っていません**（追加確認が不要）。
